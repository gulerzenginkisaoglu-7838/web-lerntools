# Web-Lerntools

Interaktive Lernwerkzeuge für HTML und JavaScript sowie eine React-Komponente zur Prüfungsvorbereitung. Entstanden in der Umschulung zur Fachinformatikerin für Systemintegration (GFN).

## Inhalt

| Datei | Beschreibung |
|---|---|
| `index.html` | Startseite mit Links zu den einzelnen Quizzen |
| `IPv4_Quiz.html` | Quiz zum IPv4-Subnetting |
| `LF09_Quiz_W1.html` | Quiz zur Netzwerktechnik (LF09, Woche 1) |
| `zahlensysteme-quiz.html` | Quiz zu Zahlensystemen |
| `IT_Grundschutz_Lernkarten.html` | Lernkarten zum IT-Grundschutz |
| `FISI_BaWue_Lernhilfe.jsx` | React-Komponente zur Prüfungsvorbereitung (benötigt eine React-Umgebung, z. B. Vite) |

## Nutzung

Die HTML-Dateien lassen sich direkt im Browser öffnen, am besten über `index.html`.

## Technologien

HTML, CSS, JavaScript, React
